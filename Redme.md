## Controle-financeiro

 * Projeto criado para estudos e controle financeiro falmiliar.
 
![preview](/src/assets/preview.png)

* NiLL's | Controle financeiro familiar
  - Aplicacao Angular standalone para acompanhar o caixa familiar, despesas, orcamento e metas compartilhadas. 
  - O backend em Java/Spring Boot expoe uma API REST e persiste os dados em tabelas PostgreSQL. 
  - O Angular mantem cache local para uso durante indisponibilidade da API e sincroniza as alteracoes quando o backend esta ativo.
